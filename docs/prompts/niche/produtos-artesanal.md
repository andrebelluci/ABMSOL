# Nicho: Produtos artesanais / serviços sensoriais (ex: Barbara Belluci)

Constraints para o **brief-architect**.

## Conceito típico

- Narrativa cinematográfica / slow living / ritual
- Não ecommerce premium genérico nem template Awwwards comum
- Usuário "descobre", não "navega por seções empilhadas"

## Chrome permitido

| Elemento | Direção |
|----------|---------|
| Cursor | Tátil: lupa "EXPLORE", modo vídeo, como tocar tecido |
| Scrollbar | Discreta, cor papel/linho; ou escondida com scroll lento (Lenis) |
| Nav mobile | Drawers / gavetas artesanais; menu como objetos de mesa |
| Hero | Mesa viva top-down, close-up, vapor, ritual — NÃO split 2-col |
| Liquid | ⚠️ Sutil: vapor, papel, luz de vela — não splash de suco |

## Estrutura

- Sequência de atmosferas (silêncio → cheiro → textura → ritual)
- Cada bloco = frame de filme
- Contato pode ser experiência (folha artesanal, selo de cera) — não form padrão

## Motion

- Scroll desacelera em momentos emocionais
- Transições dissolução cinematográfica
- Texto como tinta surgindo
- Steam/vapor layers leves

## NEVER USE (nicho)

- Grid de cards ecommerce
- Hero headline gigante + CTA tradicional
- Carrinho / vitrine Shopify
- Tipografia rounded playful
- Copiar layout de clínica ou médico
