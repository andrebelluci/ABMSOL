# Referências visuais para o brief-architect

Coloque screenshots de hero, inspirações ou frames de motion aqui.

## Fluxo Awwwards

1. Pesquisa: `docs/prompts/research-references-awwwards.md`
2. Screenshots nesta pasta (`hero.png`, `ref-01.png`, …)
3. Architect preenche `REFERENCE-LOG.md` (uma entrada por URL analisada)
4. Saída final: `BRIEF.md` → seção **Referências analisadas** + `03-hero.md`

Na sessão de briefing, o architect pode:
- Ler estes arquivos
- Abrir URLs via MCP browser
- Transcrever composição + motion para `BRIEF.md` → `03-hero.md`

Não é obrigatório ter mockup completo — screenshot + descrição da animação no INTAKE basta.

**Ambição ≥ premium:** mínimo 3 referências analisadas antes de gerar o BRIEF.
